# 📚 BelguDzBot — Telegram-бот для расписания и домашки с аналитикой

Электронный «дневник» в Telegram: ведёт **предметы**, **расписание занятий** и **домашние задания**, а также пишет **аналитику** пользователей и событий в отдельную базу данных.  
Интерфейс — русский. Часовой пояс по умолчанию — `Europe/Chisinau`.

---

## 🚀 Возможности

- 👥 Роли:
  - **Администраторы** — полный доступ к CRUD через команды и админ-панель.
  - **Пользователи** — просмотр расписания и ДЗ, отметка выполненных заданий.
- 📚 Предметы:
  - Добавление, удаление (каскадно удаляются пары и ДЗ), список.
- 📅 Расписание:
  - Добавление пары (предмет → день недели → время `HH:MM`).
  - Просмотр всего расписания.
  - Просмотр расписания на сегодня.
  - Удаление пар за сегодня.
- 📝 Домашние задания:
  - Добавление (предмет, текст, дедлайн `YYYY-MM-DD` или «нет»).
  - Просмотр списка.
  - Отметка «выполнено» (`/done_hw <id>`).
  - Удаление.
- ⚙️ Админ-панель:
  - Inline-кнопки для быстрого доступа.
- 📊 Аналитика:
  - `users`: информация о пользователях (id, username, язык, время последнего визита).
  - `events`: события (команды, сообщения, callback + raw JSON).

##📋 Команды

# Пользователи

`/start` — приветствие и справка.

`/list_subjects` — список предметов.

`/list_schedule` — полное расписание.

`/today` — пары на сегодня.

`/list_hw` — список ДЗ.

# Администраторы

`/admin` — открыть админ-панель.

`/add_subject` — добавить предмет.

`/delete_subject` — удалить предмет.

`/add_class` — добавить пару

`/delete_today_class` — удалить пару за сегодня.

`/add_hw` — добавить ДЗ.

`/delete_hw` — удалить ДЗ.
